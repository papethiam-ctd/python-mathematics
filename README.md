# Linear Algebra with Python

This project demonstrates basic linear algebra operations using Python and NumPy.

## Features

- Matrix addition
- Matrix subtraction
- Matrix multiplication

- Determinant
- Matrix inverse
- Eigenvalues

- Solving linear systems
